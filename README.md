 # Calcul de somme d'étalonnage 📈

Un outil Python permettant de lire un fichier texte ligne par ligne pour extraire les chiffres et calculer une somme d'étalonnage. 

## Fonctionnalités principales

- Lecture ligne par ligne pour éviter une surcharge de mémoire.
- Extraction des chiffres pour former des valeurs d'étalonnage.
- Gestion des cas spécifiques, comme les lignes contenant un seul chiffre.
